# چک‌لیست پروژه لاین یار — PWA

فایل‌ها را بدون تغییر ساختار در یک Repository گیت‌هاب قرار بده.

## فعال‌سازی GitHub Pages
1. Repository را در GitHub باز کن.
2. Settings → Pages
3. زیر Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Save
5. چند دقیقه صبر کن تا آدرس Pages ساخته شود.

## نصب روی iPhone
1. لینک GitHub Pages را در Safari باز کن.
2. Share را بزن.
3. Add to Home Screen را انتخاب کن.
4. Add را بزن.

بعد از اولین باز شدن آنلاین، برنامه باید بدون اینترنت هم باز شود.

## نکته
اطلاعات فرم در localStorage همان مرورگر/نصب ذخیره می‌شود. برای پروژه‌های مهم از داخل برنامه بکاپ JSON بگیر.
